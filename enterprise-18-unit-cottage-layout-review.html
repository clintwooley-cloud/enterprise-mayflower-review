Enterprise / Mayflower — 18-unit site-built cottage layouts

These are concept-only layout studies for a straight site-built cottage community using a condo/site-condo legal structure. I revised these around an average cottage footprint of about 24' x 36' (roughly 864 sf) instead of a tiny-home scale footprint. Each keeps the single Mayflower entry idea and treats the creek/sewer corridor as a real common/open-space constraint rather than trying to build through it.

Recommended starting direction

Concept E3 is now the cleanest review version because it sits directly on the actual plat background. It is still conceptual, but it fixes the earlier problem where the parcel shape and Mayflower frontage were drawn too loosely.
